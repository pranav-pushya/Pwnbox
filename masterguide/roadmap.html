PHASE 01

Build the Foundation

🎯 Primary Goal: Understand how computers and networks communicate before touching any offensive hacking concept.

Month 1 – 2 (8 Weeks)
Weeks 1 – 2 🌐

Computer & Internet Basics

  • Understand how computers communicate over packet networks (frames, packets, segments).
  • Trace the complete lifecycle of what happens when you type a URL and hit Enter.
  • Master IP addressing: IPv4 vs. IPv6, public vs. private ranges (RFC 1918).
  • DNS architecture: Root servers, TLDs, authoritative resolvers & record types (A, AAAA, MX, CNAME, TXT).
  • Learn standard service ports: 21 (FTP), 22 (SSH), 25 (SMTP), 53 (DNS), 80 (HTTP), 443 (HTTPS), 445 (SMB).
Connected PwnBox Labs & Guide:
📚 Ch 06: Network Security 🛠️ Module 01: Recon
Weeks 3 – 4 📡

Networking Deep Dive

  • OSI 7-Layer Model: Master physical, data link, network, transport, session, presentation, and application layers.
  • TCP/IP Model vs. OSI: Encapsulation and decapsulation flows.
  • IP Subnetting & CIDR: Calculate network IDs, broadcast addresses, and usable host ranges (/24, /27, /30).
  • Essential protocols: ARP resolution, DHCP DORA process, and NAT (Network Address Translation).
  • Hardware packet routing: Hubs vs. Layer-2 switches vs. Layer-3 routers & stateful firewalls.
Connected PwnBox Labs & Guide:
📚 Ch 03: Firewalls & IDS 🛠️ Module 02: Scanning
Weeks 5 – 6 🐧

Linux Fundamentals

  • Install Kali Linux in a virtual machine environment (VirtualBox / VMware).
  • Master directory navigation and file manipulation: ls, cd, pwd, cat, head, tail, grep, find, nano.
  • Linux permissions model: read/write/execute (rwx), chmod octal modes (755, 644, 400), and chown ownership.
  • Users, groups & privileges: sudoers, useradd, passwd, /etc/passwd, and /etc/shadow structures.
  • Network administration CLI: ip a, ifconfig, ss -tuln, netstat, ping, traceroute, curl.
  • Practice daily: Terminal navigation must feel as natural as using a graphical file manager by Week 6.
Recommended Practice:
🕹️ OverTheWire Bandit (0–15) 🛠️ Module 05: Linux Root
Weeks 7 – 8+ 🕸️

Web Basics & Protocols

  • How web applications are structured: HTML DOM, CSS layout, client-side JavaScript execution.
  • HTTP request-response cycle: Request headers, User-Agents, Methods (GET, POST, PUT, DELETE).
  • HTTP Status Codes: 200 (Success), 301/302 (Redirects), 400 (Bad Request), 401/403 (Auth/Forbidden), 500 (Internal Error).
  • Stateless web mechanisms: Cookies, Set-Cookie headers, Session IDs, and JWT auth tokens.

PHASE 02

Learn Core Concepts & Practice

🎯 Primary Goal: Start executing real attacks and practice hands-on exploitation in safe, legal, and controlled lab environments.

Month 3 – 5 (3 Months)
Month 3 🔍

Core Hacking & 5 Phases

  • Master the 5 formal phases of ethical hacking: Reconnaissance, Scanning, Gaining Access, Maintaining Access, Clearing Tracks.
  • Active vs. passive reconnaissance: Whois queries, DNS zone transfers, Google dorking, Harvester scraping.
  • Network scanning deep dive: TCP 3-way handshake, SYN stealth scans (-sS), UDP scans (-sU), and timing templates (-T4).
  • Service & OS fingerprinting: Understanding open, closed, and filtered port states with Nmap and Hping3.
  • Complete the TryHackMe "Pre-Security" guided learning path.
Connected PwnBox Labs & Practice:
🛠️ M-01 Recon (22+ Tools) 🛠️ M-02 Scanning (15+ Tools) 🌐 TryHackMe Pre-Security
Month 4 💻

Web Application Exploitation

  • Understand how common web vulnerabilities work at a conceptual architecture level first.
  • SQL Injection (SQLi): Error-based, UNION-based, Boolean blind, and Time-based payloads.
  • Cross-Site Scripting (XSS): Reflected, Stored, and DOM-based script injection and cookie stealing.
  • Broken Authentication, Session Hijacking, and Insecure Direct Object References (IDOR).
  • Hands-on Practice: Deploy and solve DVWA (Damn Vulnerable Web App) on low and medium security modes.
  • Hands-on Practice: Complete PortSwigger Web Security Academy free apprentice labs.
Connected PwnBox Labs & Practice:
🛠️ M-06 Web Threats 🌐 PortSwigger Web Academy
Month 5 🔐

System Hacking & Social Eng

  • Understand how attackers compromise operating systems beyond the browser (exploits, payloads, listeners).
  • Password storage & hashing mechanics: MD5, SHA-256, NTLM, and salted bcrypt.
  • Password cracking tools: John the Ripper wordlist attacks, Hashcat GPU cracking, and Hydra brute-forcing.
  • Social engineering mechanics: Spear phishing, Pretexting, Baiting, Vishing — why humans are the weakest link.
  • Compete in your first beginner CTF: Solve 25+ introductory challenges on PicoCTF.

PHASE 03

CEH Exam Preparation

🎯 Primary Goal: Systematically prepare for and clear the EC-Council Certified Ethical Hacker examination with high confidence.

Month 6 – 7 (2 Months)
Weeks 1 – 2 📚

Cover the 20 CEH Domains

  • Review all 20 CEH exam domains systematically — focus on core concepts rather than memorizing questions.
  • Heavy domain focus: Cryptography (Symmetric vs. Asymmetric, AES, RSA, Diffie-Hellman, PKI, Digital Signatures).
  • Cloud Computing & Virtualization security (AWS/Azure shared responsibility model, container attacks).
  • IoT Security & OT/SCADA threats and attack surfaces.
  • Recommended Reading: Read "CEH Certified Ethical Hacker All-in-One Exam Guide" by Matt Walker.
PwnBox Master Guide Chapters:
📚 Ch 04: Encryption 📚 Ch 06: IoT & Cloud 📚 Ch 08: Governance
Week 3 🔬

Remediate Weak Domains

  • Run diagnostic practice tests on the PwnBox Master Test engine to identify the domains you score lowest in.
  • Targeted lab rooms: Revisit concepts by completing specific TryHackMe rooms that match those weak topics.
  • Feynman Technique: Write detailed notes in your own words — explain every concept as if you were teaching someone else.
  • Memorize essential Nmap scan flags (-sS, -sT, -sU, -sN, -sF, -sX, -A, -O, -sV, -p-) and command syntax.
Practice Engine:
📝 PwnBox Master Test 📄 CEH Command Cheat Sheet
Week 4 ⏱️

Full-Length Mock Exams

  • Take full-length timed practice exams (Boson ExSim, Exam-Labs, or EC-Council official practice tests).
  • Benchmark Target: Achieve consistent scores of 80%+ across 3 consecutive practice exams before booking the test.
  • Post-Exam Analysis: Review every single wrong answer — understand why the correct answer is right and why yours was wrong.
  • Register for the exam: Schedule your testing slot via EC-Council's ECC Exam portal or a Pearson VUE test center.
