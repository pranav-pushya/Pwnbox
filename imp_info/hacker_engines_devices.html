WiFi Pineapple

// Hak5
Powerful tool for Wi-Fi penetration testing. Intercept & analyze Wi-Fi traffic.

Dual-band (2.4GHz & 5GHz) tactical wireless audit platform. Employs the proprietary PineAP suite to automatically harvest client probe requests, launch Karma attacks, broadcast spoofed SSIDs, deauthenticate authenticated clients, and establish Man-in-the-Middle (MITM) control to capture WPA handshakes and harvest credentials.

Frequencies: 2.4 GHz & 5.8 GHz (Dual Band)
Core Engine: OpenWrt Linux / PineAP Suite
Key Attack: Rogue AP, Karma, Deauth, SSL Strip
⚡ Attack Vector
Clients connect to fake Wi-Fi; attacker intercepts traffic, forces captive portals, captures NTLM/HTTP credentials.
🛡️ Defense / Mitigation
Enforce 802.1X EAP-TLS enterprise Wi-Fi, enable WPA3 Protected Management Frames (PMF), forbid auto-connect to open SSIDs.
Form: Desktop / Tactical Handheld

// Hak5
Looks like a USB drive, acts like a keyboard. Automate attacks easily.

The definitive Human Interface Device (HID) keystroke injection platform. Because operating systems inherently trust keyboards without requiring driver installation or privilege prompts, the Rubber Ducky executes DuckyScript 3.0 at over 1,000 words per minute to open terminals, disable defenses, exfiltrate credentials, and deploy reverse shells in under 5 seconds.

Interface: USB-A / USB-C HID Emulation
Language: DuckyScript 3.0 (Logic, Conditionals, Jitter)
Speed: 1000+ words per minute injection
⚡ Attack Vector
Plugged into unattended laptop; immediately spawns PowerShell, downloads memory payload, exfiltrates Wi-Fi passwords to webhook.
🛡️ Defense / Mitigation
USB port allowlisting by Hardware VID/PID, physical USB port blocker locks, GPO restrictions on Command Prompt & PowerShell.
Form: Standard USB Thumb Drive

Forces victims joining the rogue network into a walled garden where all DNS traffic redirects to a realistic login page imitating airport Wi-Fi, hotel portals, Starbucks terms, or corporate Google/Microsoft SSO logins.

Platform: WiFi Pineapple, ESP32, Linux AP Daemon
Mechanism: DNS Spoofing (Captive Portal RFC 7710/8908)
Payload: Cloned Google, Microsoft 365, WPA2 Passphrase Phish
⚡ Attack Vector
Sends deauth frames kicking users off coffee shop Wi-Fi; users reconnect to rogue twin; enter email password to regain internet.
🛡️ Defense / Mitigation
