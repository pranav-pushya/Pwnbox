01

Basic Google Dorks

💡 Tip: Combine operators for better & targeted results
Domain Scope
site:example.com
All indexed pages of a website
Target website ke sabhi indexed URLs dekhne ke liye use hota hai. Target organization ka complete attack surface map karne ka first step.
URL Path
inurl:admin
Pages with "admin" in URL
URL structure me "admin" word dhoondta hai. Administrative control panels, dashboards aur hidden management gateways target karta hai.
Page Title
intitle:login
Pages with "login" in title
Webpage ke HTML <title> tag me "login" search karta hai. Auth portals, employee SSO gates aur user sign-in forms locate karta hai.
Body Content
intext:confidential
Pages containing specific text
Page body content ke andar exact word search karta hai. Internal memos, classified policies aur non-public data leaks capture karta hai.
File Extension
filetype:pdf
PDF files
Direct Adobe Acrobat PDF files scan karta hai. Target company ke financial audit reports, whitepapers aur leaked internal guides filter karta hai.
Word Documents
filetype:doc OR filetype:docx
Word documents
Microsoft Word files dhoondta hai. Draft agreements, internal SOPs aur confidential employee contracts dhoondne ke liye critical dork.

Sensitive Information Dorks

⚠️ Tip: Always handle sensitive data responsibly
Credentials
intext:"password" filetype:txt
Text files with passwords
Admin notes, temporary scratch files ya test credentials jo `.txt` format me server par accidentally chhoot gaye hon, unhe pinpoint karta hai.
API Tokens
intext:"api key" filetype:txt
API keys in text files
Exposed OpenAI, Stripe, AWS, SendGrid aur Google Cloud API keys search karta hai jo unauthorized cloud spending aur data extraction allow kar sakti hain.
Confidential Docs
intext:"confidential" filetype:pdf
Confidential documents
NDAs, board meeting minutes, upcoming mergers, security audit findings aur proprietary IP reports uncover karta hai.
Access Anomalies
intext:"access denied"
Pages showing access issues
WAF blocks, 403 Forbidden endpoints ya poorly configured access control mechanisms ko trace karta hai jahan authorization bypass testing possible hai.
Open Directory
"index of" / "backup"
Backup or directory listings
Web server ki misconfigured directory indexation (Apache/Nginx mod_autoindex) jisme backup/, old/, ya .tar.gz folders direct browseable ho jate hain.
Source Config
inurl:config filetype:php
Config files (PHP)
PHP web applications ke configuration files (e.g. config.inc.php, db_config.php) jahan database host, username aur password secrets hote hain.
04

Advanced Operator Dorks

💡 Tip: Combine operators like a pro to narrow results
Subdomain Recon
site:example.com -www
Results from specific site excluding www
Target website ke main www host ko exclude karke hidden subdomains, dev portals, test environments (e.g. dev.example.com, vpn.example.com) discover karta hai.
SQLi Vector
inurl:php?id=
Pages with id parameter
URL me dynamic numeric/string ID parameters dhoondta hai. Bug bounty hunters iska use SQL Injection (SQLi) aur Insecure Direct Object Reference (IDOR) parameters test karne ke liye karte hain.
LFI / RFI / SSRF
inurl:"?page="
Pages with page parameter
Dynamic page include parameters search karta hai. Local File Inclusion (LFI), Remote File Inclusion (RFI) aur Server-Side Request Forgery (SSRF) attack surface pinpoint karta hai.
Directory Traversal
intitle:"index of"
Directory listing pages
Web servers jahan default index.html missing hai aur server directory tree public kar deta hai. Isme uploaded media, source scripts aur internal zips milte hain.
Entity Correlation
related:example.com
Websites related to a domain
Google ke algorithm ke mutabiq target organization ke similar ya partner websites detect karta hai. Subsidiary aur third-party vendor supply chain audit ke liye useful.
Historical Snapshot
cache:example.com
Cached version of a site
Google ke crawler ka saved cache snapshot open karta hai. Deleted pages, defaced websites, ya recently removed sensitive information dekhne ke liye perfect.

06

Useful Tips & Best Practices (Ethical Code)

🛡️ Official Cyber Mind Space Protocol
🎯 BE SPECIFIC

Use precise keywords and multiple chained operators for accurate results and lower noise. Broad terms flood your query with irrelevant public articles.

⚖️ STAY ETHICAL

Use Google Dorking strictly for authorized security assessments, responsible bug bounties, and educational defense. Unauthorized exploitation of leaked secrets is illegal under international law.

🔀 COMBINE OPERATORS

Combine multiple operators (e.g., site: + filetype: + intext: + -inurl:) to refine your search from 50,000 messy hits down to 5 critical target endpoints.

🔍 VERIFY RESULTS

Always verify information against current scope before taking action. Google cache might show historical artifacts that have already been remediated or rotated.

🛡️ RESPECT PRIVACY

Do not misuse, download, exfiltrate, or share sensitive PII, healthcare records, or private credentials uncovered during reconnaissance. Report discovered exposures immediately via responsible disclosure.

💡 KNOWLEDGE IS POWER

"Knowledge is power. Use it responsibly. Hack the planet ethically." — Keep learning, maintain defensive integrity, and always protect digital infrastructure.
