💡 WHAT THIS TEACHES: CIDR NOTATION, VLSM & SUBNET MASKS

Classless Inter-Domain Routing (CIDR) and Variable Length Subnet Masking (VLSM) prevent global IPv4 address depletion. Every subnet loses exactly 2 addresses: the first address (Network ID, all host bits zero) and the last address (Broadcast ID, all host bits one). To compute usable hosts for a prefix /N, apply the formula Usable Hosts = 2^(32 - N) - 2. Over-provisioning leads to IP exhaustion, while under-provisioning halts departmental growth.
