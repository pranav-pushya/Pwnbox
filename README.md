# 🛡️ PwnBox Academy

> **Note:** This is a private, closed-source educational project. All rights reserved.

PwnBox Academy is an elite, interactive cybersecurity training platform designed to take learners from absolute beginners to advanced operators. Built with a stunning, high-contrast Bauhaus UI and an immersive "True Dark Mode", the platform provides hands-on modules, dynamic progress tracking, and an extensive knowledge base covering the core pillars of ethical hacking.

Designed & Developed by **Pranav Pushya**.

---

## 🚀 Key Features

### 1. 📂 Core Interactive Modules
The platform tracks your journey through 6 critical phases of penetration testing. Each module contains detailed methodologies, attack vectors, and defensive strategies:
- **Module 01:** Recon & Footprinting
- **Module 02:** Network Scanning
- **Module 03:** System Enumeration
- **Module 04:** Vulnerability Analysis
- **Module 05:** System Hacking
- **Module 06:** Web App Threats

### 2. 📖 CyberSec Master Guide ("Zero to Cyber")
A comprehensive, multi-page glossary breaking down **100 essential cybersecurity terms** across 10 structured chapters (Core Threats, Malware Types, Defensive Tools, Encryption, IAM, Network/Cloud, Advanced Threats, Governance, Operations, Emerging Tech). Features real-world analogies, attack flow diagrams, and historical breach examples.

### 3. 🛠️ Custom Tool Arsenal
Users can build their own personalized arsenal! The platform allows you to:
- Add custom tools and commands.
- Categorize tools dynamically.
- Edit and manage default payload lists.

### 4. 📄 CEH Command Cheat Sheet
A quick-access sliding drawer containing the most critical, real-world terminal commands for all phases of a penetration test (Nmap, Hashcat, MSFvenom, Wfuzz, SearchSploit, etc.). Features 1-click payload copying.

### 5. 🏆 Gamified Progress Tracking & Operative Profiles
- **Persistent Local State:** Your progress, custom tools, and unlocked modules are saved securely in your browser's local storage.
- **3D Tactical Agent ID:** The profile menu is an immersive, 3D-flipping ID card. Hover to flip and reveal your Operative Settings!
- **Dynamic Avatars:** Edit your Alias and watch the system automatically generate a bespoke avatar using your initials, or choose a hacker emoji.
- **Next Rank Intelligence:** The ID card tracks your progress and actively displays your precise next mission objective to rank up (e.g., from *Apprentice* to *Elite Agent*).
- **Interactive Roadmap:** A visual SVG timeline tracks your journey across the cybersecurity landscape.

### 6. 🎨 Brutalist Bauhaus UI
A complete visual overhaul featuring a premium, structured Bauhaus design philosophy.
- **Immersive Loader:** A custom 3-second geometric startup animation to build immersion.
- **Custom Modals:** Native browser alerts have been stripped out and replaced with styled Bauhaus drop-down modals (like the "Erase Data" warning).
- **Custom Favicons:** Dynamic SVG favicons specifically styled for the dashboard vs. the master guide.
- **Stark geometric borders** and solid drop shadows with vibrant primary colors (Bauhaus Red, Blue, Yellow).
- Seamless **Global Dark Mode** that intelligently adapts across the main dashboard, sidebars, master guide, and cheat sheets.

## ⚙️ Installation & Usage

Since PwnBox Academy is built entirely on vanilla web technologies (HTML, CSS, JavaScript) without backend dependencies, it can be run instantly on any machine.

1. Clone or download the repository to your local machine.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Brave).
3. Ensure JavaScript is enabled for progress tracking, tool management, and dark mode features to work properly.
