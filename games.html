💡 WHAT THIS TEACHES: SQL INJECTION MECHANICS & PARAMETERIZATION DEFENSE

SQL Injection occurs when untrusted user input is directly concatenated into a dynamic SQL string. A single quote ' prematurely closes the string literal, Boolean operators like OR 1=1 force the record lookup condition to evaluate to true, and comment syntax like -- or # truncates the remaining query (such as password checks). In modern defense, Prepared Statements / Parameterized Queries ensure input is treated strictly as data parameters rather than executable SQL command tokens.

💡 WHAT THIS TEACHES: CIDR NOTATION, VLSM & SUBNET MASKS

Classless Inter-Domain Routing (CIDR) and Variable Length Subnet Masking (VLSM) prevent global IPv4 address depletion. Every subnet loses exactly 2 addresses: the first address (Network ID, all host bits zero) and the last address (Broadcast ID, all host bits one). To compute usable hosts for a prefix /N, apply the formula Usable Hosts = 2^(32 - N) - 2. Over-provisioning leads to IP exhaustion, while under-provisioning halts departmental growth.
