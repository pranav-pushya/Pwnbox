PRIVACY POLICY & DATA HANDLING CHARTER

Effective Date: October 2026 • Platform Build: v3.4.0 • Architect: Pranav Pushya

00

EXECUTIVE DATA DISCLOSURE

PwnBox is engineered on a Privacy-First, Client-Centric architecture. We do not operate persistent user account databases, do not sell behavioral data, do not run intrusive tracking pixels, and do not profile your web activity. Your lab progress, simulation scores, and operative notes reside locally inside your own browser.

01

CLIENT BROWSER STORAGE (LOCALSTORAGE)

To provide persistent game progression, terminal custom tools, and notes across browser restarts without requiring cloud logins, PwnBox utilizes HTML5 localStorage on your local device. The specific keys saved are:

  • theme: Your interface display mode preference ('dark' or 'light').
  • pwnbox_xp / userXP: Gamification experience points earned in the 8 kill-chain labs.
  • pwnbox_operative_name / operative_callsign: Custom tactical alias you select for your session.
  • pwnbox_notes: Personal study notes written inside the tactical notepad (notes.html).
  • pwnbox_completed_modules: Completion tracking across Footprinting, Scanning, Enumeration, Vulnerability, System Hacking, Web App Threats, OSINT, and BlackOps.
  • pwnbox_sound_enabled: Audio effect toggle for arcade simulations and terminal typing sound.
  • pwnbox_custom_tools: Custom penetration testing shortcuts you add in the module labs.
  • pwnbox_cookie_consent: Your preference regarding optional anonymous performance telemetry.
TACTICAL PURGE: ERASE ALL LOCAL STORED DATA

You maintain full sovereign control over your machine. Clicking the button below will immediately wipe all PwnBox keys from your browser's localStorage and reset your session.

02

AI ASSISTANT (GROQ CLOUD INFERENCE)

When you interact with the AI SOC Assistant (ai_assistant.html) or the floating tactical assistant widget, your prompt messages are securely transmitted via HTTPS through our serverless Firebase Cloud Function proxy (/api/chat) to Groq Cloud's high-speed inference API (Llama 3.3 70B Versatile).

  • No User Data Training: User queries are processed ephemerally in volatile memory for live response generation and are not utilized to train foundational LLMs.
  • Backend Secret Protection: API authorization tokens are securely stored in Google Secret Manager and are never exposed to the client-side JavaScript bundle.
  • Zero Identifiers: We do not attach personal names, email addresses, or device hardware IDs to LLM queries.
03

HOSTING INFRASTRUCTURE & TECHNICAL LOGS

PwnBox is deployed on Google Firebase Hosting and backed by Google Cloud Platform (GCP) global edge CDN nodes. When your browser requests resources from https://pwnbo-x.web.app, standard technical HTTP web server access logs are automatically generated by the underlying network infrastructure:

  • Your device's public IP address (for geographical routing and DDoS rate limiting).
  • Request timestamp and HTTP protocol version.
  • User-Agent string (browser type and operating system).
  • Uniform Resource Identifier (URI) requested and response status code (e.g. 200 OK, 404 Not Found).

These logs are maintained by Google Cloud for infrastructure reliability, abuse mitigation, and server health monitoring under Google Cloud's enterprise security compliance.

04

SERVICE WORKERS & OFFLINE ASSETS

PwnBox includes a Progressive Web App (PWA) Service Worker (sw.js). This script caches static styling, fonts, and 3D Three.js hardware assets in your browser's Cache Storage API so the academy can be accessed offline without sending recurring network requests. You may clear this cache anytime via your browser's Developer Tools (Application → Storage → Clear site data).

05
